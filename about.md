# About

<p class="lede">Indie developer with a particular interest in private, on-device artificial intelligence, cross-platform interfaces, and systems that respect user privacy.</p>

I work primarily in Java (including modern JavaFX desktop UIs) and Swift / SwiftUI for Apple platforms. Recent focus has been Ara — a local agentic AI assistant — together with the accompanying Vex protocol system for structured tool use and multi-agent coordination.

Other interests include privacy-preserving tooling, efficient local inference (GGUF, MLX and related stacks), self-hosting, and the intersection of hardware and software design.

I prefer dense, minimal interfaces that stay out of the way.
