# Projects

<p class="lede">A selection of public and ongoing work.</p>

### Ara

Private on-device agentic AI assistant. Features a JavaFX desktop UI, local GGUF inference via java-llama.cpp, streaming chat, optional encryption, and deep integration with the Vex protocol system for tool calling and agent orchestration. All inference and data remain on-device.

[Repository](https://github.com/OliverRawden/Ara)

### Vex

Protocol editor and complex command system that defines structured agent behaviour. Designed to work both with Ara and independently across multiple models and tools.

(Private repository)

### This site

A deliberately minimal Jekyll site hosted on GitHub Pages. Clean typography, system font stack, automatic light/dark mode, and no unnecessary dependencies.
