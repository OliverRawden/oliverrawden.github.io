Ara · v5.5

On-device AI assistant

A desktop chat application that runs large language models entirely on your machine — no cloud inference, no API keys. Built with JavaFX and java-llama.cpp.

GitHub (private) Companion: Vex

Highlights

  • Streaming chat with Cupertino dark/light themes
  • Background GGUF model preload for fast first replies
  • Agent tools via Vex protocols (terminal, web, memory)
  • Optional AES-256-GCM encryption for chats & memory
  • Audit log for tool calls and privacy events
  • Native installers via jpackage (macOS, Windows, Linux)

Requirements

JDK 21+ (Java 25 recommended). Gradle wrapper included.

# Run from source
git clone https://github.com/OliverRawden/Ara.git
cd Ara
./gradlew :app:run

Agent tools (Vex sync)

Tools are defined as Vex protocols and auto-loaded into every system prompt.

ID Tool Purpose
101execute_commandShell commands with confirmation UI
102get_current_datetimeCurrent date and time
103web_searchDuckDuckGo Lite search
104read_memoryRead persistent context.md
105write_memoryReplace persistent memory
106append_memoryStructured memory append

Data layout

All runtime data under ~/Documents/Ara/

PathContents
models/GGUF model files
data/chats.jsonChat sessions
data/settings.jsonApp preferences
context.mdLong-term AI memory
logs/audit.logTool & privacy audit trail

Recommended model

Qwen2.5-7B-Instruct Q4_K_M (~4.5 GB) — downloadable from Settings → Model, or place any .gguf in the models directory.
