Vex · v0.2

Protocol orchestration console

Define, store, and execute protocols and functions from markdown files. Type expressions like 2 | 9 in the built-in console — and manage the ara-tool schemas that power Ara.

GitHub (private) Companion: Ara

Domain concepts

  • Protocols — commands stored as .md in ~/Documents/Vex/Protocols/
  • Functions — linkers like pipe (|) in ~/Documents/Vex/Functions/
  • Projects — user markdown docs in ~/Documents/Vex/Projects/
  • Console — terminal-style execution view

Console syntax

1 # Run protocol 1
2 | 9 # Protocol 2 + overdrive
16 {4} # Emergency, severity 4
10 # Kill — abort pipeline

Pipe rule: modifier on the right runs in context of the left. 10 aborts the left side.

Ara integration

Vex is the control plane for Ara's agent tool catalog.

Ara watches ~/Documents/Vex/Protocols/ and injects the full catalog into every inference prompt. When you edit an ara-tool protocol in Vex, Ara picks up the change on the next file refresh.

Tool calls use ara-tool names (e.g. get_current_datetime), not protocol IDs.

# Run from source
git clone https://github.com/OliverRawden/Vex.git
cd Vex
./gradlew :app:run
