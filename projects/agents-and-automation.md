The AI system I run my own work on: several agents sharing one set of notes and one task list, with a person approving anything that matters.

| | |
|---|---|
| **For** | My own work, and the base for Email Autopilot |
| **Tools** | Claude, Grok, Obsidian, TickTick |
| **Status** | Running |

## How it works

- An Obsidian vault is the shared memory for every agent, with written rules for what each one may read and change.
- TickTick is the shared task list. Each agent tags its own tasks, and anything that needs a human decision comes to me as a task.
- Specialist bots handle research, business admin and video work.

## Space Cuts Daily

A YouTube Shorts channel run by a video agent, which cuts and packages official
NASA and ESA footage into two Shorts a day.
